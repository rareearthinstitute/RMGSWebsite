Use Claude with GovWin IQ (Claude for Chrome)

How it works: put Claude on GovWin IQ with the Claude for Chrome extension. It reads and operates the GovWin pages you already have open, using your existing GovWin login — so you work GovWin right in the browser.

You'll need: a paid Claude plan (Pro, Max, Team, or Enterprise), Google Chrome (desktop), and a valid GovWin IQ login. Claude for Chrome is a beta / research preview; your org admin may need to allowlist the site.

  1. Install the Claude for Chrome extension from the Chrome Web Store ("Add to Chrome").
  2. Sign in with your RMGS Claude account, then pin the extension (puzzle-piece icon → pin next to Claude).
  3. In the Claude desktop app, open Settings and enable the Chrome connector if prompted.
  4. Log in to GovWin IQ at iq.govwin.com as you normally would.
  5. Open the Claude side panel on the GovWin tab and grant site access when the "Permission required" prompt appears. Set GovWin to "always allow" under the extension's Settings → Permissions to approve it once and keep going.
  6. Put Claude to work on the page — for example: "Summarize the opportunities in this GovWin search and score them against our fit criteria."

Reference: Get started with Claude in Chrome, Claude in Chrome permissions guide.

Give Claude access to SharePoint (Microsoft 365 connector)

SharePoint access comes from the built-in Microsoft 365 connector. Once enabled, Claude searches across SharePoint (plus OneDrive, Outlook, and Teams). Access stays read-only: Claude finds and analyzes content while your files, edits, and permissions remain exactly as they are.

You'll need: an RMGS Microsoft 365 work account on a Microsoft Entra business tenant — use your RMGS work account, since personal @outlook.com / @hotmail.com accounts fall outside the tenant. An RMGS org Owner completes the first step once.

Org admin — one time

  1. As an RMGS org Owner, open Settings → Connectors (Customize → Connectors) and enable Microsoft 365 for the organization.
  2. Authenticate with Microsoft 365 admin credentials and grant admin consent on behalf of the organization (this approves the M365 connector apps in your Entra tenant).
  3. Optionally restrict which SharePoint sites or content the connector can reach, per RMGS policy.

Each user

  1. In Claude, go to Customize → Connectors, find Microsoft 365, and click "Connect."
  2. Sign in with your RMGS Microsoft 365 credentials and accept the read-only permissions.
  3. In a chat, enable the Microsoft 365 connector, then ask Claude to search SharePoint — for example: "Search our SharePoint for the latest past-performance write-ups on [customer]."
